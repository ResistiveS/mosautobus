# mosautobus
Максимально примитивное расписание автобусов Москвы с веб-мордой на next

Общее назначение

Это веб-приложение (дашборд) для мониторинга расписания и прогноза прибытия общественного транспорта (автобусов, трамваев и т.д.) на выбранных остановках. Система позволяет группировать остановки в отдельные панели (дашборды) для удобного отслеживания.

Структура интерфейса

1. Левая боковая панель (Навигация)
Разделена на два функциональных блока:

    Остановки: Список всех добавленных в систему остановок. Название остановок тянется из данных по API. После изменения название запоминается и остается неизменным.

    Дашборды: Список созданных пользователем панелей. 

2. Основная рабочая область (Дашборд)

    Заголовок: Название текущего дашборда 

    Панель управления видом (справа вверху):

3. Карточки остановок (Сетка)
В основной области отображаются карточки с данными по каждой остановке.
